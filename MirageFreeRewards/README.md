## Что это

MirageFreeRewards добавляет игрокам команду `/free` с красивым меню бесплатных наград: ежедневные и недельные бонусы, стартовые подарки, донат-награды по праву. Меню открывается с анимацией, оформление строится вокруг белого цвета `&f` и красной палитры (`#EE3F3F`, `#B33535`, `#F72B2B`), которую можно сменить в один блок конфига или прямо в игре.

Настраивать плагин можно двумя способами, как вам удобнее:

- **в игре**: `/free edit` открывает GUI-редактор (по духу как меню DeluxeMenus, но без правки файлов);
- **в конфиге**: `config.yml` и `rewards.yml`.

Оба способа работают с одними и теми же файлами и дополняют друг друга.

## Возможности

### Меню и анимации
- Анимированное открытие: по рамке бежит «волна», затем награды появляются одна за другой со звуком.
- Три стиля анимации: `SPIRAL` (по кругу), `CENTER_OUT` (от центра), `ROWS` (по рядам).
- Мерцание рамки, пока меню открыто (цикл материалов настраивается).
- Живое обновление: таймеры кулдауна в меню обновляются раз в секунду.
- От 3 до 6 рядов, рамка и заполнитель включаются и выключаются отдельно.
- Инфо-предмет и кнопка закрытия настраиваются (материал, название, описание, слот).
- Разное оформление награды для каждого состояния: доступна, кулдаун, получена, заблокирована.

### Награды
- **Три типа**: `COMMAND` (команды), `ITEM` (предметы), `DONATE` (донат-награды по праву).
- Выдача **командами** с префиксами: `[console]`, `[player]`, `[message]`, `[broadcast]`, `[sound]`.
- Выдача **предметов** двумя способами: строкой `МАТЕРИАЛ:кол-во[:Название]` или готовым предметом из руки/курсора (сохраняются зачарования, названия и т. д.). Если инвентарь полон, остаток падает на землю.
- **Кулдауны**: секунды, «один раз» (`-1`), без ограничений (`0`).
- **Права**: награда заблокирована, пока у игрока нет нужного права (подходит для донат-рангов через LuckPerms и аналоги).
- Свободный или ручной слот в меню, иконка, название, описание, свечение.

### Игровой редактор (`/free edit`)
- Список всех наград с пролистыванием: создание, редактирование, удаление.
- Редактор награды: иконка (предметом с курсора), название, описание, тип, команды, предметы, кулдаун, право, слот, свечение, включение и выключение, тестовая выдача себе.
- Выбор слота визуально, прямо в макете меню.
- Настройки: заголовок, число рядов, анимации, стиль, цвета темы.
- Текстовый ввод через чат (`отмена`, чтобы вернуться).
- Предпросмотр меню одной кнопкой.

### Цвета и оформление
- Обычные коды `&f`, `&l` и т. д., HEX `&#RRGGBB`, градиенты `<gradient:#RRGGBB:#RRGGBB>Текст</gradient>`.
- **Цветовая тема** (`theme` в `config.yml`) с плейсхолдерами `{primary}`, `{secondary}`, `{accent}`, `{text}`, `{muted}`, `{error}`. Смените палитру в одном месте, и перекрасится всё: меню, сообщения, редактор.
- Цикл мерцания рамки (`animation.idle.cycle`) задаётся материалами, подберите под свою палитру.

### Прочее
- Все сообщения и звуки настраиваются в `config.yml`.
- Данные игроков хранятся в `data.yml`.
- В плагине указано авторство MirageStudio / sawervatoryy (`/free about`, инфо-предмет, консоль, редактор).

## Установка

1. Скачайте готовый `MirageFreeRewards-1.0.0.jar`.
2. Положите `.jar` в папку `plugins/`.
3. Запустите сервер: создадутся `config.yml`, `rewards.yml`, `data.yml`.
4. Настройте награды через `/free edit` или в файлах, затем `/free reload`.


## Команды и права

| Команда | Описание | Право |
| --- | --- | --- |
| `/free` | Открыть меню наград | `mirage.free.use` (по умолчанию у всех) |
| `/free edit` | Игровой редактор | `mirage.free.admin` |
| `/free reload` | Перезагрузить конфиг и награды | `mirage.free.admin` |
| `/free reset <игрок\|*> [награда]` | Сбросить получение наград | `mirage.free.admin` |
| `/free give <игрок> <награда>` | Выдать содержимое награды без кулдауна | `mirage.free.admin` |
| `/free about` | Информация о плагине | без права |

Алиас: `/freerewards`.

**Подсказка администратору:** в меню `/free` Shift+ПКМ по награде сразу открывает её редактор.

## Настройка наград (`rewards.yml`)

```yaml
rewards:
  vip:                                  # id награды
    enabled: true
    name: "<gradient:#F72B2B:#B33535>&lVIP-награда</gradient>"
    icon: NETHER_STAR
    slot: -1                            # -1 = авто, иначе номер слота
    type: DONATE                        # COMMAND | ITEM | DONATE
    cooldown: 86400                     # секунды; -1 = один раз; 0 = без ограничений
    permission: mirage.free.vip         # нет права = награда заблокирована
    glow: true
    lore:
      - "{text}Для донатеров. Раз в сутки."
    commands:
      - "[console] give {player} diamond 5"
      - "[message] {secondary}Спасибо за поддержку!"
    items:
      - "EXPERIENCE_BOTTLE:16"
      - "DIAMOND:2:{secondary}Алмаз удачи"
```

### Типы наград

| Тип | Когда использовать |
| --- | --- |
| `COMMAND` | Награда выдаётся командами (валюта, ключи, эффекты) |
| `ITEM` | Награда это предметы |
| `DONATE` | Донат-награда: если нет права из `permission`, в меню показывается блок `menu.donate-lock-lore` |

Типы отличаются оформлением и логикой блокировки; содержимое (`commands`, `items`) можно использовать в любом типе.

### Префиксы команд

| Префикс | Действие |
| --- | --- |
| `[console]` | От имени консоли (по умолчанию, если префикса нет) |
| `[player]` | От имени игрока |
| `[message]` | Сообщение игроку |
| `[broadcast]` | Сообщение всем |
| `[sound]` | Звук игроку, например `[sound] entity.player.levelup` |

Плейсхолдеры: `{player}`, `{uuid}`.

### Донат-награды

Донатные награды строятся на правах: задайте `permission` и выдавайте это право донат-рангам через LuckPerms или любой другой менеджер прав. Если права нет, награда отображается заблокированной. Команды наград могут вызывать любые плагины: Vault, PlayerPoints и так далее. Например, `[console] points give {player} 50`.

## Настройка меню (`config.yml`)

| Блок | Что настраивает |
| --- | --- |
| `theme` | Цветовая палитра всего плагина |
| `menu` | Заголовок, ряды, рамка, заполнитель, инфо-предмет, кнопка закрытия, оформление состояний |
| `animation.open` | Анимация открытия: стиль, скорость, «голова» волны |
| `animation.idle` | Мерцание рамки: интервал и цикл материалов |
| `sounds` | Звуки: `"ключ,громкость,высота"` |
| `messages` | Все сообщения плагина |

### Смена цветовой темы

Достаточно изменить `theme`:

```yaml
theme:
  primary: "&f"
  secondary: "#EE3F3F"
  accent: "#B33535"
  bright: "#F72B2B"
  text: "&7"
  muted: "&8"
  error: "&c"
```

Затем подберите материалы мерцания в `animation.idle.cycle` и `animation.open.head-material` под новые цвета (панели нужного оттенка). Темой можно управлять и из игры: `/free edit` → **Настройки**.

## Файлы

| Файл | Назначение |
| --- | --- |
| `config.yml` | Тема, меню, анимации, звуки, сообщения |
| `rewards.yml` | Список наград |
| `data.yml` | Время получения наград игроками (не редактируйте вручную) |

> **Важно:** когда вы сохраняете награды через игровой редактор, `rewards.yml` перезаписывается и комментарии в нём пропадают. Если хотите сохранить комментарии, правьте этот файл вручную. Это же относится к `config.yml` при смене настроек из игры.

## FAQ

**Меню не открывается.** Проверьте право `mirage.free.use` (по умолчанию есть у всех) и логи при старте.

**Награда пишет «недоступна».** У игрока нет права из `permission` этой награды.

**Как сбросить кулдаун игроку?** `/free reset <игрок> [награда]`, либо `/free reset *` для всех.

**Как поменять цвета на свою палитру?** Блок `theme` в `config.yml` или `/free edit` → Настройки.
