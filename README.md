# MirageFreeRewards
MirageFreeRewards добавляет игрокам команду /free с красивым меню бесплатных наград: ежедневные и недельные бонусы, стартовые подарки, донат-награды по праву. Меню открывается с анимацией, оформление строится вокруг белого цвета &amp;f и красной палитры (#EE3F3F, #B33535, #F72B2B), которую можно сменить в один блок конфига или прямо в игре.
